Short-cut rules

General rules:

  • Sum rule: d/dx (f(x) + g(x)) = f'(x) + g'(x)
  • Constant multiple rule: d/dx (c·f(x)) = c·f'(x)
  • Constant function rule: d/dx (c) = 0
  • Power rule: d/dx (xⁿ) = n·xⁿ⁻¹
  • Exponential rule: d/dx (aˣ) = aˣ ln(a)

Trigonometric function rules:

  • d/dx (sin x) = cos x
  • d/dx (cos x) = −sin x
  • d/dx (tan x) = sec² x

Other core rules:

  • Product rule: (f·g)' = f'·g + g'·f
  • Quotient rule: (f/g)' = (g·f' − f·g') / g²
  • Chain rule: (f(g(x)))' = f'(g(x)) · g'(x)
  • Log rule: d/dx (ln x) = 1/x

Inverse trig rules:

  • d/dx (arctan x) = 1 / (1 + x²)
  • d/dx (arcsin x) = 1 / √(1 − x²)

More trig rules:

  • d/dx (cot x) = −csc² x
  • d/dx (sec x) = sec x · tan x
  • d/dx (csc x) = −csc x · cot x
